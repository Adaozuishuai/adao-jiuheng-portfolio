# 首页重构：Experimental Editorial / B

## 范围

本轮只交付本地首页重构，没有提交、推送或部署。保留原有作品和博客路由、数据查询以及非首页的自由投篮。首页作品引用现有项目数据；三个封面是生成的概念视觉，页面标注为“概念探索”，不是已上线项目截图。没有详情地址的作品不伪装成可点击链接。

## 设计系统

- 1488px 内容上限，桌面 56px、平板 32px、手机 20px 外边距。
- 暖白 #f2f0eb、炭黑 #262724、砖红 #a94b40、细分割线 #d9d7cf。
- 原 Georgia SVG 字形拆成 JIU / HENG，沿用原描边及填充动画。JIU 砖红，HENG 炭黑；单一可访问标题 Jiuheng。
- 12 列作品布局：左 7 列宽幅及横幅，右 5 列纵向封面；700px 以下按阅读顺序单列。
- 结构：DAO 导航 → 分体 Hero / 单篮球单篮筐 → Selected Work → About → Writing → 极简页脚。

## 文件

- app/page.tsx：服务端首页、作品/文章数据与 About、Writing。
- app/home.css：限定在首页的设计样式与响应式布局。
- app/globals.css：移除已不使用的旧首页布局规则，保留共享 Logo 动画。
- components/hero-intro.tsx：复用原路径的分体 Logo。
- components/home/basketball-scene.tsx：投篮时间轴、SVG 篮筐前后层、可访问按钮和 SVG 降级球。
- components/home/ball-renderer.ts：懒加载 Three.js 真实球体、程序纹理和资源释放。
- components/basketball-entry.tsx、app/layout.tsx：首页与内页篮球入口分离。
- public/images/home/{interface,agents,practice}.webp：三个本地概念封面。

## 篮球

没有新增依赖；复用现有 Three.js。此单对象动画采用 requestAnimationFrame 和二次贝塞尔路径，不额外引入 GSAP 或刚体引擎。

时间轴约 2.34 秒：0–0.14 秒轻压缩，0.14–1 秒飞行，1–1.22 秒入网，随后下落、两次衰减反弹和轻微滚动，停在 Hero 底部。每次从当前位置再次投篮。前篮圈及网覆盖球体，后篮圈位于球体之后；轨迹只在提示和飞行阶段出现。进球后爱心反馈持续 700ms，不记录公开分数。

首屏文字服务端输出；先显示位置一致的静态球，在 Logo 入场结束后异步准备 Three.js。皮革纹理由开发脚本预生成成 512×256 的本地 WebP（32840 字节），访客端不再现场绘制 32768 个颗粒。使用异步着色器预编译及隐藏首帧，再平滑接入三维球。移动使用 translate3d，重复尺寸回调不再重置球体和画布。移动端降低球面细分和 DPR。场景离屏、后台标签页暂停；静止后停止动画帧；卸载释放 WebGL、纹理、监听器和观察器。

无法创建 WebGL 或上下文丢失时显示 SVG 球，投篮按钮仍可用。减少动态效果启用时跳过三维初始化、浮动及复杂飞行，仅反馈进球状态。按钮至少 48px，支持回车和空格，进球由 output 状态区播报。

## 图像生成记录

使用内置 imagegen 工具，未使用外部 API 密钥。原始 PNG 保留在 Codex generated_images 目录，网页采用 WebP。

1. interface：1536×1024。提示方向：摄影级建筑静物，薄磨砂玻璃面板与深色球体，暖灰海岸空间，右重左轻、留白用于标题；无文字、标志或发光 UI。
2. agents：1024×1536。提示方向：蓝灰背景，匿名人像雕塑的侧面轮廓，细白轨道，画廊摄影风格；无机器人、文字或霓虹。
3. practice：1536×1024。提示方向：砂色与陶土色的球场建筑构成，白色弧线与斜线、真实混凝土纹理、日光影子；无人物、篮球、篮筐或文字。

输出体积：108588 + 81932 + 290338 = 480858 字节（约 470 KiB）。第一张优先加载，其余懒加载，由 Next Image 输出响应式图像。

## 验证与边界

- TypeScript、生产构建、修改文件的 Oxlint、Git 空白差异检查通过。
- 本地浏览器检查 1440、768、620、390、320px；未发现横向溢出，手机重新排版。620px 修正了字标与介绍间距，平板篮球触控尺寸下限为 48px。
- 点击、空格、回车触发投篮；确认到达 rest，状态区播报，重复投篮可用。首页只有一个篮球及一个篮筐；作品页仍有原自由投篮。
- 完成作品、博客导航的本地检查。
- 减少动态效果及 WebGL 丢失分支已实现并进行代码检查，未通过真实设备强制触发验收；没有宣称 Lighthouse 分数或低端手机帧率。当前预览工具的缩放快捷键没有改变页面缩放，因此没有将其记作 200% 放大通过。
- 后续最有价值的工作是替换真实项目案例内容、制作详情，以及实机测试低性能设备。数据库、后台和文章发布流程不属于本轮重构验收。
